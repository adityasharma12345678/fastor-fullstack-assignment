# Firebase Phone Authentication Setup

The local frontend defaults to Fastor assignment mode. Firebase Phone Auth is an optional demo mode. Real SMS delivery needs a Firebase project owned or accessible to you; Firebase API keys, project IDs, and SMS configuration cannot be generated by this repository.

## 1. Create a Firebase project and Web app

1. Open the [Firebase Console](https://console.firebase.google.com/) and create or select a project.
2. In **Project settings → General → Your apps**, add a **Web app**.
3. Copy the Web app configuration values. Firebase Web API keys are client configuration; restrict them to the application as appropriate in Google Cloud.

## 2. Enable phone sign-in

1. In Firebase Console, open **Authentication → Sign-in method**.
2. Enable the **Phone** provider and save.
3. In **Authentication → Settings → Authorized domains**, ensure `localhost` is listed.
4. Review the phone-number SMS region policy and ensure the destination region is allowed.

## 3. Configure the frontend

From `frontend/`, create `.env` from `.env.example` if it does not exist:

```powershell
Copy-Item .env.example .env -Force
notepad .env
```

Set these exact values from the Firebase Web app settings:

```dotenv
VITE_AUTH_MODE=firebase
VITE_FIREBASE_API_KEY=<apiKey>
VITE_FIREBASE_AUTH_DOMAIN=<authDomain>
VITE_FIREBASE_PROJECT_ID=<projectId>
VITE_FIREBASE_APP_ID=<appId>
VITE_FIREBASE_MESSAGING_SENDER_ID=<messagingSenderId>
```

The Firebase Web config can be found in the SDK setup snippet in **Project settings → General → Your apps**. Keep the keys paired with the same Firebase project. Do not commit `frontend/.env`.

## 4. Install and start

From the repository root:

```powershell
cd C:\RN\fastor-fullstack-assignment\frontend
npm install
npm run dev
```

Open `http://localhost:5173`. If Vite selected a different port, use the displayed URL and authorize `localhost` in Firebase. Restart Vite after any `.env` change.

## 5. Request and verify a real OTP

1. Select the country calling code and enter the national number without its trunk prefix, or enter the complete international number beginning with `+` (for example `+14155552671`).
2. Select **Get OTP**. Firebase's invisible reCAPTCHA may display a challenge. Complete it if shown.
3. Firebase sends an SMS if the phone number is valid, the project configuration permits the region, and quota/security checks pass.
4. Enter the received six-digit code and select **Continue**.
5. Firebase verifies the code and the application creates a browser-local session, then navigates to `/restaurants`.

Firebase may impose SMS quotas, billing requirements, abuse controls, or regional restrictions. A Firebase test phone number can be used for development but does **not** send a real SMS; remove test numbers to verify delivery to a real handset.

## Environment variables

| Variable | Required | Purpose |
|---|---|---|
| `VITE_AUTH_MODE` | No | `assignment` (default) or `firebase` (optional demo). |
| `VITE_FIREBASE_API_KEY` | Firebase mode | Firebase Web API key. |
| `VITE_FIREBASE_AUTH_DOMAIN` | Firebase mode | Firebase Authentication domain. |
| `VITE_FIREBASE_PROJECT_ID` | Firebase mode | Firebase project identifier. |
| `VITE_FIREBASE_APP_ID` | Firebase mode | Firebase Web app identifier. |
| `VITE_FIREBASE_MESSAGING_SENDER_ID` | Firebase mode | Messaging sender ID from Web app config. |

`VITE_API_BASE_URL` is only used in `assignment` mode. Firebase's browser ID token is not accepted by Fastor's restaurant API.

## Common errors

- **Firebase Phone Auth is not configured:** one or more Web app variables are missing; fill them in and restart Vite.
- **Unauthorized domain:** add `localhost` in Firebase Authentication's authorized domains and use `http://localhost:5173`.
- **Phone number invalid:** use E.164 format or select the correct country and provide its national number.
- **Too many requests / quota exceeded:** wait for the quota window or review Firebase project limits and SMS settings.
- **Operation not allowed:** enable the Phone provider in Firebase Authentication.
- **SMS never arrives:** confirm region policy, number format, project quota/billing settings, and Firebase console logs. Firebase controls actual SMS delivery.
